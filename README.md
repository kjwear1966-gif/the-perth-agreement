# The Perth Agreement

One meal. Every person. Every day.

A framework so no person goes hungry. Open for examination, refinement, and responsible development.

If independent examination produces a better way, that way replaces what is here. The goal is the assurance, not any particular design.

Site: https://the-perth-agreement.vercel.app (or custom domain when pointed)

## Transparency
This repository is public. Ideas that meet simple rules appear on the open record. Challenges are published with responses. Unresolved disagreements stay visible.
